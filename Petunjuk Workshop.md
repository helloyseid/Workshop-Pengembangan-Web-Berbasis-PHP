# Workshop Pengembangan Web Berbasis PHP

Selamat datang di repository **Workshop Pengembangan Web Berbasis PHP**.

Repository ini berisi seluruh materi dan latihan (hands-on) yang akan digunakan selama workshop berlangsung. Setelah workshop selesai, repository ini juga dapat digunakan sebagai bahan belajar mandiri untuk mengembangkan kemampuan pemrograman web menggunakan PHP.

---

## Tujuan Workshop

Setelah mengikuti workshop ini, peserta diharapkan mampu:

- Memahami bagaimana sebuah website bekerja.
- Mengenal peran HTML, CSS, dan PHP dalam pengembangan website.
- Menyiapkan lingkungan pengembangan (development environment) menggunakan XAMPP.
- Menulis kode PHP dasar.
- Membuat halaman website yang terdiri dari beberapa halaman.
- Menggunakan variabel, percabangan, dan perulangan.
- Menggunakan **include** untuk membuat kode lebih rapi.
- Membuat form sederhana.
- Mengembangkan website sederhana menggunakan PHP.

## Hands-on (Mini Project)

Selama workshop kita akan membuat sebuah website sederhana secara bertahap.

Setiap materi akan langsung diikuti dengan praktik sehingga peserta dapat memahami konsep sambil melihat hasilnya.

Target akhir workshop adalah membuat sebuah website profil sederhana menggunakan PHP.

---

## Software yang Digunakan

Pastikan software berikut sudah terpasang.

- XAMPP
- Visual Studio Code
- Google Chrome atau Microsoft Edge

---

## Struktur Project

Selama workshop kita akan menggunakan struktur project berikut.

```text
workshop-php/

│
├── assets/
│   └── css/
│       └── style.css
│
├── header.php
├── footer.php
├── index.php
├── tentang.php
├── galeri.php
└── kontak.php
```

---

## Folder Project

Seluruh project akan disimpan pada folder:

```
C:\xampp\htdocs\
```

Contoh:

```
C:\xampp\htdocs\workshop-php
```

---

## Menjalankan Website

Aktifkan:

- Apache
- MySQL *(opsional)*

Kemudian buka browser.

```
http://localhost/workshop-php
```

Apabila berhasil, website akan tampil pada browser.

---

## Tips Selama Workshop

✅ Ikuti langkah sesuai urutan.

✅ Jangan takut mencoba.

✅ Jika muncul error, baca kembali pesan error dengan teliti.

✅ Biasakan menjalankan program setiap selesai menulis kode.

✅ Jangan hanya copy-paste, tetapi usahakan memahami setiap baris kode.
